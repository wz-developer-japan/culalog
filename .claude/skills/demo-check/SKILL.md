# デモの流れの確認

1. 手元で確かめるときは、開発サーバーを起動する（`rm -rf .next` → `npx next dev -p 3100` をバックグラウンドで）
2. `node scripts/smoke.mjs`（本番なら `node scripts/smoke.mjs https://culalog.vercel.app`）
3. すべて `ok` なら終わり。`NG` があれば、`scripts/out/` の画面の画像（番号はステップの順）を見て原因を探す

## 確かめていること
- 時計を 2026-11-07 10:00（東京）に固定して、日付に関わる表示をいつ動かしても同じ条件で見る
- Claude の答えでないもの（キーが無いときの仮の結果・仮の答え）に「仮」と出ていること
- けがの頼みごとで、学校のお知らせと傷害保険の証券の両方から引用が出て、学校名だけの行が引用になっていないこと
