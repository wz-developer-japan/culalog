## 数え方

- 正解は、デモ素材の正解 JSON をアプリの形（Extraction）にしたもの（src/data/photoSamples.json の provisionalDraft）。見本はすべて架空で、期間中に新しく作ったもの
- 予定は「名前が近くて日付（終わりの日も）が同じ」で1点。種類（提出・満了・受付期間…）は別に1点。「知っておくだけ」は正解でそうなっている予定だけ数える
- 「読めなかった所を推測で埋めない」は、正解で読めなかった所がある書類（写真が切れている・別紙が無い・曜日が合わない）は読み取りでも空でないこと、無い書類では空であること
- 「判断の言い回しが無い」は、要約・項目・予定の名前に「補償されます」「解約したほうが」「受診すべき」などが混ざっていないこと
- 日付の規則が合っているか・読めるかの判断は人が見る。このスクリプトは数えるだけ（判断はしない）
