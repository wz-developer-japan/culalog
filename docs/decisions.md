# 作りながら決めたこと

CULALOG を作る途中で迷ったところと、そのときに選んだこと・理由の記録です。
会期中に新しく決めたものだけを、決めた順に近い形でまとめています。

## 守る線

- **判断をしない。** 保険・医療・法律について「補償されます」「解約して大丈夫です」とは言いません。
  執事が出すのは「どの書類のどこに何と書いてあるか」と「問い合わせ先」までです。
  「うちの場合は保険が使える可能性があります」のような当てはめも言いません。最終的な確認は原本と窓口でお願いしています。
- **判断を書く欄を作らない。** Claude に返させる形（構造化出力）そのものに、「対象になります」などの結論を書く場所がありません。
  文の中に判断の言い回しが混じった答えは、コードが出さずに止めます。
- **日付の計算はコード。** 期限の逆算（例: 有給の申請は1週間前まで）・何日前かの計算・くり返す期限の次の回は、すべてコードで計算します。
  Claude の答えの中の日付も、コードで書類の日付と照らし合わせます。
- **採用するのは本人。** 執事の気づき（例: 「運動会の予備日にも休みが要るかもしれません」）は、本人がボタンを押すまで予定に入りません。
- **原本と見比べて確定するまで、根拠に使わない。** 読み取った下書きは、本人が原本と見比べて確定したものだけを、ひとこと・予定・聞くの根拠にします。
- **仮のものは仮と出す。** Claude を呼べないとき（キーが無い・回数の上限）に使う仮の結果・仮のひとこと・仮の気づき・仮の答えは、画面に必ず「仮」と出します。
- **気づきは言い切らない。** 「〜かもしれません」という提案までにしています。

## 書類の扱い

- **書類のデータは端末の中に置く。** 読み取った内容・写真・予定・覚えたことは、ブラウザの中（IndexedDB）にだけ保存します。
  Claude に頼むときだけ、必要な部分をサーバー経由で Claude API に送り、サーバーには残しません。
- **送るときは番号を伏せる。** 聞く・つなぐで書類の中身を送るときは、証券番号などの番号を伏せ、電話番号は送りません。
  写真の中の番号は伏せられないため、そのことは README に正直に書いています。
- **大事な番号は端末の中で答える。** 年金・雇用保険・印鑑登録・証券番号のような、めったに見ないのに手続きで急に聞かれる番号は、
  「○○の番号は？」「○○持ってる？」と聞かれたら Claude に送らずに、確定した書類からコードで探して答えます。
  番号は伏せて表示し、「見る」を押したときだけ見せます。聞いた記録にも番号そのものは残しません。
- **年度の取り違えを防ぐ。** 書類ごとに「何年度のものか・いつまで有効か」を持たせ、同じ種類の新しい書類（改訂版など）が来たら、
  古い方を「前のもの」にするかを本人に聞きます。前のものは、ひとこと・予定・聞くの根拠に使いません。
- **メールは貼り付けで受け取る。** メールで届く書類は、本文の貼り付け・スクショ・PDF で渡せます。
  メールのアカウントに自動でつなぐ機能は作っていません（「これから」は README に）。

## メールで届く書類

家に届くメールのうち、期日を覚えておく価値があるものはごく一部で、残りは宣伝や利用の通知です。そのため、次のようにしています。

- **予定と「知っておくだけ」を分ける。** 本人が動かないと困るもの（申し込み・提出・支払い・止めるなら申し出）と、
  自動で引き落とされる・自動で継続するなど、知っておくだけのものを分けます。知っておくだけのものは、予定のひとことや期限の知らせには出さず、
  すべての予定・書類の画面で見られるだけにしています。
- **同じ予定は束ねる。** 1つの期日について、初回のお知らせ・督促・前日の通知と何通も届くことがあります。
  日付が同じで名前の言葉が重なる予定は、予定では1件にまとめ、「同じ予定のお知らせがほかに○通」と添えます。
- **済んだお知らせで閉じる（決めるのは本人）。** 「納付完了」「退会完了」などのお知らせを確定したら、つながりそうな予定について
  「済みましたか？」と聞きたいことに並べます。勝手に済んだにはしません。
- **訂正は「済んだ」と区別する。** 「お支払い期限の訂正」「日程変更」のように前のお知らせの予定が置き換わるメールは、
  済んだのではないので、「この書類で訂正されましたか？」と聞き、前の予定だけを消して訂正後の予定を残します（入金の確認とは混ぜません）。
- **束ねた予定は、済んだも一緒。** 束ねた何通かのうち、どれか1つを済んだにすれば（本人が押しても、済んだお知らせから答えても）、束ね全体を予定で知らせなくなります。
  取り消すときも一緒に戻します。同じ束ねの中の予定について、同じ質問を2回はしません。
- **リンク先にしか無いことは、推測で埋めない。** 金額や満了日が本文に無く、リンクの先にしか無いときは、
  「リンク先にしか書いてありません。開いて確かめてください」と出します。アプリはリンクを開きません。
- **日付が何種類も並ぶときは、別々の予定にする。** 保険の満期日・自動継続の日・止める場合の申し出の締切・決済の予定日などを、
  原本の書き方のまま別の予定として読み、取り違えないようにしています。

## 撮って、まとめて渡すだけ

- **人はいっぺんに投げ、執事はコツコツ読む。** 何枚でも受け取り箱に入れ、画面を開いているあいだに1枚ずつ読みます。
  閉じても、次に開いたときに続きから読みます。回数の上限に当たったら、時間をおいて自動で続けます。
- **分からないことは、あとでまとめて聞く。** 読みながら分からなかったこと（誰の書類か など）は「聞きたいこと」に並べ、
  空いた時間に選択肢で答えてもらいます。答えは「覚えたこと」として残し、同じ種類の書類では二度聞きません。
  覚えたことは Claude には送らず、読み取りのあとにコードで当てはめます。
- **原本だけでは決められないことは、埋めずに外す。** 写真の下が切れて振替日が写っていない・「別紙参照」なのに別紙が無い・「12月5日（日）」と書いてあるのに12月5日は土曜、
  のようなときは推測で埋めず、「読めなかった所」として理由を添えてまとめて確定から外し、原本で確かめてもらいます。
  二つの書類で同じ行事の日付が食い違うときは、どちらかを選ばず両方を予定に出して、違いに気づけるようにします。
- **同じものに気づく。** 同じファイルは二度読みません。同じ書類の写真違い（種類が同じで、予定の名前と日付が全部同じ）は
  「同じ書類ですか？」と聞きます。改訂版や日付違いは、写真違いと取り違えないよう「前のものにしますか？」の方へ回します。
- **登録したときにはもう過ぎていた締切は騒がない。** 古いプリントをあとから撮って渡したとき、間に合わない締切で予定が埋まらないよう、
  トップ・予定では期限切れとして知らせず、すべての予定の画面にだけ「登録したときには、もう過ぎていました」と添えて残します。
  登録したあとに過ぎたものは、今まで通り知らせます。
- **知らせたら終わりにしない。** 「済んだ」を押していない締切は、1週間前・3日前・前日にもう一度ひとことに出します。

## Claude とコードの分担

- **候補を作るのはコード、何を言うか選ぶのは Claude。** 予定のひとことは、コードが期日の逆算・来ていない書類・聞きたいことから候補を作り、
  Claude が数件を選んで言い回しを付けます。締切が3日以内・過ぎたのに選ばれなかったものは、コードが必ず別に出します（取りこぼし防止）。
- **Claude の答えは、ID と言い回しで返させる。** 予定・書類・きまりの ID だけを返させ、日付・原本の場所はコードが持っているものを出します。
  実在しない ID や、書類と違う日付が入った答えは出しません。
- **呼ぶ回数を絞る。** つなぐ＋ひとことは、書類・きまりが変わったときと日付が変わったときだけ呼び、結果は端末に保存します。
- **執事の名前は Claude に送らない。** 名前は利用者が自由に付けられますが、口調はキャラの種類だけで決め、名前は画面でコードが差し込みます。
  名前に変な文を入れられても、答えの中身は変わりません。

## 中身は正確に、温度は柔らかく

- 執事の名前・口調・あいさつは、続けて使ってもらうための工夫です。キャラを変えても、期日・引用・原本の場所・判断しない線・迫った期限の警告は同じです。
- 公開の説明では「AI に感情がある」とは言わず、「人が続けて使えるように温度を持たせた」と書いています。
- 作っていない機能（端末内の暗号化など）は、README でも「ある」とは書きません。

## 誰のものか

- **トップから全部に行けて、どこからでも1回で戻れる。** 開くとトップ（メニュー）。家族の丸いアイコン・いちばん近い締切1件・6つの入口（予定・書類・家族ごと・大事な番号・聞く・わが家のきまり）。
  どの画面にも左上に「‹ トップ」、下のタブの左端も「トップ」です。
- **誰のか書類から分からないものは、勝手に誰かに入れない。** 読み取りで誰のことか言い切れないときは、宛名の人に寄せず「誰のか分からない」のまま執事が聞きます。
  住まい・光熱・通信・家財の保険・家の車・町内会などは「家全体」として、ひとりのページには出しません（その人のことでもあるときだけ、その人にも出します）。
  二人以上に関係する書類（現況届と就労証明書など）は、その全員に出します。この家の書類ではないもの（記入例・見本）は誰にも出しません。

## デモ

- **前提知識なしで試せる入口。** 最初の画面の「架空の家族で試す」と、渡す画面の「写真の見本をまとめて渡す」で、すぐに流れを試せます。
- **デモの家族・会社・書類はすべて架空。** 会期中にこのリポジトリのために作り、名前は架空と分かるもの、電話番号は 000- で始まるものにしています。
- **デモの日付は開いた日が基準。** いつ開いても同じ流れを試せます（写真の見本だけは撮影日を基準にした画像のため、日付が動きません）。
